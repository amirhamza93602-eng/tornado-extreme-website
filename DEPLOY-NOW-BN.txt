TORNADO EXTREME PORTAL — DEPLOY CHECKLIST (UPDATED BUILD)

IMPORTANT: This ZIP is arranged for Netlify manual deploy.

1) Extract this ZIP.
2) Open the extracted folder. You should directly see index.html, portal-admin.html,
   portal-dashboard.html, portal-profile.html, and the assets folder.
3) In Netlify, open the Tornado Extreme site → Deploys.
4) Drag-and-drop the CONTENTS of this extracted folder (not the ZIP file and not
   a parent folder containing another nested folder) into the manual deploy area.
5) Wait until deploy status is Published.
6) Open /portal-admin.html and press Ctrl+Shift+R.
