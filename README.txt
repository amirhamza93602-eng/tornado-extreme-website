TORNADO EXTREME — MULTI-PAGE WEBSITE PHASE 1

HOW TO OPEN:
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Use the top navigation to visit each separate page.

Pages included:
- Home
- About
- Teams
- Players
- League Center
- Achievements
- News
- Contact

The logo and shared theme CSS are inside the assets folder.
This is a static website prototype. It is not hosted online yet. Login, shared database, admin permissions, and dynamic result submissions require a later backend phase.
